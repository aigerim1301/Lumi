✕ Классические Google Forms
• Высокий отток: до 45% пользователей закрывают опрос, не дойдя до конца.
• Скучный UX: длинные списки радиокнопок вызывают «баннерную слепоту».
• Односторонний обмен: респондент тратит время, не получая ничего полезного.
• Рутина автора: составление вопросов вручную отнимает часы.

Ограничение целостности БД

В модели Response заложено жесткое ограничение на уровне ядра базы данных:

unique_together = ('survey', 'respondent')

Пользователь не может отправить повторный ответ даже при попытке отправить прямой POST-запрос или манипуляции с браузером.

🤖 Встроенный AI-генератор

Создание опроса за 1 секунду

Автор вводит только тему (например, «Качество онлайн-курса по веб-разработке»). Алгоритм классифицирует тему и строит идеальную структуру:

✓ 1 Вопрос-свайп (быстрое вовлечение)
✓ 1 Термометр эмоций (-4..+4)
✓ 1 Звёздный рейтинг (оценка полезности)
✓ 2 Вопроса с одиночным и мультивыбором
✓ 1 Текстовое поле для пожеланий

REST API & Тесты Аудит защищенности

REST API и 43 автоматических теста

5 эндпоинтов Django REST Framework:

GET /api/me/ Профиль пользователя
GET /api/surveys/ Каталог опубликованных
GET /api/surveys/<id>/ Детальная структура
POST /api/surveys/<id>/respond/ Отправка ответов
GET /api/surveys/<id>/stats/ Только для автора (403)
Поддерживает Session и Basic Auth, полную JSON-валидацию входных пакетов.
